## Featured Project — RiskPilot

<div align="center">

[![RiskPilot](https://github-readme-stats.vercel.app/api/pin/?username=imranadas&repo=RiskPilot&theme=tokyonight&hide_border=true&description_lines_count=3)](https://github.com/imranadas/RiskPilot)

[![Live Demo](https://img.shields.io/badge/%F0%9F%9A%80%20Live%20Demo-risk--pilot--beta.vercel.app-00C7B7?style=for-the-badge&logo=vercel&logoColor=white)](https://risk-pilot-beta.vercel.app)

</div>

AI-powered credit intelligence SaaS — processes **CIBIL / Experian / Equifax / CRIF** bureau reports in **< 30 seconds** using **Groq's Llama 3.3 70B**. Delivers explainable risk scoring, lending decisions, and portfolio analytics for loan officers.

| | |
|---|---|
| **AI Engine** | Groq · Llama 3.3 70B · Extracts 14 structured financial fields per report |
| **Risk Output** | Low / Medium / High classification + Approve / Review / Reject + INR credit limit |
| **Stack** | Next.js 14 · TypeScript · Supabase · PostgreSQL · Tailwind CSS · Recharts |
| **Infra** | Vercel · Supabase Auth · Supabase Storage (private bucket) · RLS policies |
| **Key Features** | PDF drag-and-drop · 5-factor weighted scorecard · EMI/income ratio chart · PDF export |
